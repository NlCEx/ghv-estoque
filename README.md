# GHV Estoque

Aplicativo de controle de estoque — Paramentação Médica.

- **Frontend:** este repositório (HTML/CSS/JS estático), publicado via GitHub Pages.
- **PWA:** instalável no celular (ícone na tela inicial, tela cheia).
- **Backend (futuro / Fase 2):** Google Apps Script + Google Sheets como API de dados.

## Estrutura
- `index.html` — o aplicativo (tela, layout responsivo PC/celular).
- `manifest.json` — configuração do PWA.
- `service-worker.js` — cache para funcionamento offline parcial.
- `icon-192.png` / `icon-512.png` — ícones do app.

## Login (provisório, no cliente)
- GHV — `ghv`
- CONFORTEL — `ct`
- JMSA — `jm`
